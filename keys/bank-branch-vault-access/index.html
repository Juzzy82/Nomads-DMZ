Bank Branch Vault Access key

MW4 DMZ locked door key · Cheongun Village

Type
Locked door key
Area
Cheongun Village
Map square

How to get the key
Random loot, found on a teller counter inside the bank.

Where to use it

  • Use the card on the access reader inside a Hanex bank branch: Cheongun Village (F4), Wolves Stadium, Songdo Wharf or South Hajin. Restore power with a Car Battery first. The vault keypad needs a four-digit code, and a note inside gives three of the digits.
